# Design Direction

## Overall Feel

Create a **clean, premium, modern software-studio website** with a mostly monochrome visual system.

The design should feel deliberate and human-designed rather than like a generic AI-generated agency template.

Use:

- white / off-white
- black / charcoal
- soft greys
- one restrained accent colour

The accent should appear only in selected places such as:

- primary CTAs
- active controls
- small status indicators
- illustration highlights
- selected UI details

Do not make the whole website colourful.

---

## Typography

Keep typography strong, simple and spacious.

### Primary font
**Outfit**

Use it for:

- major headings
- body copy
- navigation
- buttons
- primary UI text

### Secondary / technical font
**IBM Plex Mono**

Use it sparingly for:

- small technical labels
- code-like text
- system indicators
- compact metadata

Do not overuse the mono font.

---

## Layout

Use generous whitespace and clear hierarchy.

Prefer:

- strong typography
- clean alignment
- thin borders
- restrained shadows
- spacious sections
- asymmetric compositions where useful
- a mixture of full-width, split and grid layouts

Do not make every section a row of identical cards.

Avoid repetitive:

> text → divider → text → divider → text

Change the visual rhythm naturally from section to section.

---

## Custom Illustrations

A major part of the website should be **original Nydrex-specific illustrations**.

Create custom visuals using elements such as:

- browser windows
- mobile product screens
- dashboards
- workflow cards
- automation nodes
- connected UI blocks
- charts
- forms
- status controls
- product components
- abstract line systems

The illustrations should communicate what Nydrex actually builds.

Examples of useful visual concepts:

> Customer → Portal → Operations → Automation

or:

> Business Problem → Nydrex → Software System

or:

> Form → API → CRM → Notification

The visual should have a functional meaning rather than being decoration only.

---

## Hero

Keep the hero visually simple and confident.

Recommended structure:

- strong headline
- short supporting copy
- one primary CTA
- one secondary CTA
- custom Nydrex illustration / system visual

Avoid:

- random floating spheres
- unnecessary 3D objects
- generic AI glows
- large decorative gradients
- heavy animation for the sake of animation

The hero visual should feel like a software/product illustration.

---

## Product & Service Visuals

When showing software capabilities, use believable custom UI compositions.

For example:

- desktop operations workspace
- mobile customer portal
- connected automation flow
- dashboard modules
- workflow components

Do not copy a real SaaS product interface.

Do not use meaningless fake metrics simply to fill space.

---

## Photography

Avoid generic rectangular stock photos.

If people or photos are used, integrate them into the visual system through:

- custom masks
- geometric crops
- UI frames
- layered interface compositions

Photography should feel like part of the product illustration rather than a separate stock image.

---

## Cards, Borders & Surfaces

Use:

- thin light-grey borders
- subtle corner radius
- soft shadows where needed
- simple flat surfaces

Avoid:

- excessive glassmorphism
- strong neon glow
- heavy gradients
- over-rounded pill-card layouts everywhere

---

## Motion

Keep motion subtle.

Good examples:

- light hover response
- small card shift
- button feedback
- simple dropdown transitions
- small line or connector animation
- restrained illustration movement

Do not turn the website into an animation demo.

The site should still feel complete and premium when motion is disabled.

---

## Navigation

Desktop navigation should be simple and uncluttered.

Mobile should use a proper menu / hamburger treatment rather than squeezing all desktop links into one row.

Primary navigation:

- Services
- Work
- About
- Contact
- Start a project
